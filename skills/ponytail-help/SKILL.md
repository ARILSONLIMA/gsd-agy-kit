# Ponytail Help — Guia Rápido de Comandos

| Comando | Descrição |
| :--- | :--- |
| `/ponytail` | Exibe o nível atual do modo sênior dev (ou ativa no padrão `full` se desligado). |
| `/ponytail lite` | Nível leve: constrói a solução apontando opções menores para escolha. |
| `/ponytail full` | Nível padrão: aplica a Escada de Decisão completa e YAGNI estrito. |
| `/ponytail ultra` | Nível rigoroso: questiona e recusa premissas arquiteturais sem justificativa. |
| `/ponytail off` | Desativa o modo Ponytail na sessão atual. |
| `/ponytail-review` | Revisão sênior focada em corretude, segurança, escala, testes e enxugamento. |
| `/ponytail-audit` | Auditoria completa do repositório rankeada por criticidade e potencial lean. |
| `/ponytail-debt` | Mapeia todos os comentários `shortcut:` e `TODO(gsd):` no código. |
| `/ponytail-help` | Exibe esta tela de ajuda. |
