# Caveman Help — Guia Rápido de Comandos

| Comando | Descrição |
| :--- | :--- |
| `/caveman` ou `/caveman status` | Exibe o status e regras ativas da voz concisa. |
| `/caveman ultra` ou `/ultracave` | Ativa a compressão extrema em fragmentos telegráficos diretos. |
| `/caveman off` | Desativa o modo conciso e retorna à comunicação convencional. |
| `/caveman-review` | Code review cirúrgico de 1 linha por achado (`🔴 bug:`, `🟡 risco:`, etc.). |
| `/caveman-commit` | Mensagem de commit convencional sem floreios e focada na intenção técnica. |
| `/caveman-compress <arquivo>` | Comprime arquivos de regras/markdown para reduzir tokens de entrada com backup seguro. |
| `/caveman-help` | Exibe esta tela de ajuda. |
