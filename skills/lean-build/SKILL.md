# Lean Build — Construção Enxuta e Focada

Construa a funcionalidade com o menor escopo necessário que resolva o problema observável.

- Derive critérios de aceitação objetivos e declare o que NÃO será construído (non-goals).
- Entregue um fluxo de ponta a ponta coeso atravessando as camadas necessárias (tracer bullet vertical).
- Reutilize o que já existe no repositório; não duplique código nem crie abstrações de uso único.
- Omita modos, opções, configurações e polimentos que o requisito não pediu explicitamente.
- Pare a implementação imediatamente quando o critério de aceitação for comprovado.
