# graphify: Grafo de Arquitetura

- Para entender dependências macro entre módulos desconhecidos sem abrir múltiplos arquivos, consulte `graphify query "<pergunta>"`, `graphify path "<A>" "<B>"` ou `graphify explain "<símbolo>"` (sincronize com `graphify update .` ao alterar estrutura de módulos).
